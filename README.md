# Loan Data Analysis using Advanced Excel

## Project Overview

This project focuses on analyzing a loan application dataset using Microsoft Excel.

The dataset contains 1,095 loan application records with information related to applicants, credit history, loan applications, and loan types.

## Dataset

The provided dataset includes the following information:

- Loan Application Date
- Customer ID
- Department / Designation
- Credit Score
- Past Loans
- EMI Defaults
- Date of Birth
- New Loan Application Amount
- Loan Type

## Analysis Performed

The project involved answering 10 business questions using the provided loan dataset.

Excel techniques were used for:

- Data filtering
- Formulas and calculations
- Data analysis
- Working with applicant and loan information
- Deriving answers from the provided dataset

## Project Outcome

All 10 assigned questions were answered correctly.
